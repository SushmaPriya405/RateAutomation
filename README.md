# 🚀 AMOD Automation - Complete Package

## Quick Start Guide
**Ready to Run Package - No Installation Required**

### 📋 How to Use:

#### 1. **Start AMOD:**
   - Double-click `START-AMOD.bat` 
   - Wait for browser to open automatically
   - Web interface will load at http://localhost:3003

#### 2. **Quick Start (Alternative):**
   - Double-click `QUICK-START.bat` for instant startup

#### 3. **Stop AMOD:**
   - Double-click `STOP-AMOD.bat` when done
   - Or close the command window

### 🎯 Web Interface Usage:

1. **Upload Excel Files:**
   - Click "Choose File" 
   - Select your test case Excel file
   - Choose LOB (Line of Business)
   - Click "Upload and Process"

2. **Run Tests:**
   - After upload, tests will be listed
   - Click "Start Testing"
   - Monitor progress in real-time
   - Download reports when complete

### 📁 Package Contents:

- `app.js` - Main application launcher
- `server.js` - Backend server
- `START-AMOD.bat` - **Main startup script**
- `QUICK-START.bat` - Quick launcher
- `STOP-AMOD.bat` - Stop script
- `config/` - Configuration files
- `pages/` - Page object models
- `tests/` - Test automation scripts
- `utils/` - Utility functions
- `web-interface/` - Web UI files
- `testdata/` - Sample test data
- `node_modules/` - Dependencies (pre-installed)

### ⚙️ Technical Details:

- **Platform:** Windows 64-bit
- **Browser:** Chrome/Edge required for tests
- **Port:** 3003 (default)
- **No Installation:** Everything pre-bundled

### 🔧 Troubleshooting:

- **Port 3003 busy:** Stop other apps using port 3003
- **Browser doesn't open:** Manually go to http://localhost:3003
- **Server won't start:** Run as Administrator
- **Need help:** Contact automation development team
